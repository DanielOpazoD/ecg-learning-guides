# Guías y simuladores clínicos

Archivo de cuatro guías y simuladores preparados con Firecrawl, con una página de entrada compartida para electrocardiografía, ecocardiografía y ventilación mecánica.

Sitio: https://danielopazod.github.io/ecg-learning-guides/

## Contenido

- **The Heart in Twelve Leads:** 27 capítulos, 137 puntos clave y 164 referencias. [Abrir aplicación](heart-in-twelve-leads/index.html) · [Índice de textos](heart-in-twelve-leads/LEEME.md).
- **Coronary Culprit:** 7 módulos y 39 pasos, 28 escenarios, 14 casos, 24 preguntas de comprobación, Drill, Challenge y presentación. [Abrir aplicación](coronary-culprit/sitio/index.html#course) · [Índice de textos](coronary-culprit/LEEME.md).
- **Intro2Echo — The Heart by Ultrasound:** 22 capítulos principales, 11 complementarios, el índice de bonus y tres secciones adicionales conservadas; 89 preguntas, 14 tablas de valores normales y bibliografía. [Abrir aplicación](intro2echo/sitio/index.html) · [Índice de textos](intro2echo/LEEME.md).
- **Vent Lab:** 30 lecciones y 52 actividades, 15 opciones de modo, 7 perfiles de paciente y 27 plantillas de desafío, con un caso de ejemplo de cada una. [Abrir aplicación](vent-lab/sitio/vent-lab.html) · [Índice de textos](vent-lab/LEEME.md).

El contenido original está en inglés. Las carpetas contienen los textos extraídos y los archivos de las aplicaciones interactivas. Los ejercicios generan variaciones de forma dinámica; se conserva el programa que las produce. Las sesiones en vivo y otros servicios externos requieren internet.

## Publicación

GitHub Pages publica la raíz de la rama `main`. El archivo `.nojekyll` permite servir los archivos estáticos directamente. [Documentación de GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

Para consultar los archivos sin conexión, descarga el repositorio y abre `index.html`. Intro2Echo necesita un servidor local para cargar sus módulos JavaScript: su carpeta incluye `Abrir Intro2Echo.command` para macOS. Las demás aplicaciones pueden abrirse desde sus archivos HTML. Las sesiones en vivo y las clasificaciones compartidas requieren los servicios originales en línea.
