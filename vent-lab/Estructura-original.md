# Estructura publicada de Vent Lab

El servidor entrega `vent-lab.html`, con estilos y cinco bloques principales de JavaScript incrustados: motor físico, trazado de curvas, lecciones, desafío de asincronías y controlador de la aplicación. El HTML también incluye un bloque de configuración de analítica.

Los archivos públicos enlazados son `lb-config.js`, `lb.js`, la biblioteca Supabase desde una CDN y las fuentes de Google Fonts. Estos recursos se guardaron para la copia local.

`fuentes-originales/vent-lab.html` es la respuesta original sin modificar. `sitio/vent-lab.html` utiliza rutas locales para la biblioteca y las fuentes; el cargador de analítica externo se omitió. Los módulos principales permanecen incrustados tal como fueron recibidos.

Las carpetas `curso/`, los documentos Markdown y los archivos de extracción JSON se prepararon para consulta; no representan una estructura de carpetas del autor que no haya sido publicada.
