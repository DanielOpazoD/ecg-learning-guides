# 26. tag

Dificultad: hard

Ejemplo generado por el motor original. La plantilla puede producir otras variantes.

## Situación

The mode display is hidden. Classify the mode from the scalars.

## Pregunta

Which TAG fits?

1. VC-CMVs (AC/VC)
2. PC-IMV(1)s,s (APRV)
3. VC-IMV(1)s,s (SIMV-VC + PS)
4. PC-CMVa (PRVC)

## Respuesta del original para este ejemplo

PC-CMVa (PRVC)

## Explicación

Every breath has square pressure and decaying flow (pressure control), all mandatory, but the pressure changes from breath to breath as the ventilator adapts to reach a volume target: adaptive targeting, PC-CMVa.

## Qué observar

Define the TAG: control variable, breath sequence, targeting scheme.
