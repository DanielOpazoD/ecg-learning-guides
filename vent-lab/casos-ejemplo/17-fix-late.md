# 17. fix-late

Dificultad: medium

Ejemplo generado por el motor original. La plantilla puede producir otras variantes.

## Situación

The patient works hard to start each breath.

## Pregunta

What is the best fix?

1. Lengthen Ti
2. Raise PEEP
3. Increase the set RR
4. Make the trigger more sensitive (lower the pressure threshold or switch to flow triggering)

## Respuesta del original para este ejemplo

Make the trigger more sensitive (lower the pressure threshold or switch to flow triggering)

## Explicación

This is late trigger: a long pressure dip before each breath. With an appropriately sensitive trigger, modern ventilators respond in < 100 ms; flow triggering generally takes less effort than pressure triggering.

## Qué observar

Long negative pressure dip before inflation.
