# 03. auto

Dificultad: easy

Ejemplo generado por el motor original. La plantilla puede producir otras variantes.

## Situación

Intubated for an exacerbation of obstructive lung disease. The nurse says the blood pressure keeps drifting down.

## Pregunta

What does the flow scalar show?

1. Circuit leak with false triggers
2. Early cycle
3. Failed triggers
4. Expiratory flow never returns to zero: dynamic hyperinflation (auto-PEEP)

## Respuesta del original para este ejemplo

Expiratory flow never returns to zero: dynamic hyperinflation (auto-PEEP)

## Explicación

Each new breath starts while gas is still flowing out: expiratory flow does not return to baseline. That is air trapping (auto-PEEP), which raises intrathoracic pressure and impairs venous return.

## Qué observar

Check that expiratory flow reaches zero before every breath. Quantify with an expiratory hold.
