# 12. false-card

Dificultad: medium

Ejemplo generado por el motor original. La plantilla puede producir otras variantes.

## Situación

Deeply sedated after cardiac surgery, heart rate in the 110s. The flow trigger is set very sensitive.

## Pregunta

Which patient-ventilator interaction is this?

1. Early trigger
2. Failed trigger
3. False trigger
4. Late trigger

## Respuesta del original para este ejemplo

False trigger

## Explicación

Small rhythmic oscillations in the flow scalar at the heart rate cross the very sensitive flow trigger and fire breaths with no patient effort: false trigger from cardiac oscillations.

## Qué observar

Oscillations in expiratory flow that match the heart rate, with triggered breaths but no Pmus.
