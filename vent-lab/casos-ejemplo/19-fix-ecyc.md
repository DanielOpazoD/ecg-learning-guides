# 19. fix-ecyc

Dificultad: medium

Ejemplo generado por el motor original. La plantilla puede producir otras variantes.

## Situación

Fibrotic lungs on PSV. Breaths look short and choppy.

## Pregunta

What is the best adjustment?

1. Lower the cycle threshold (ETS %) so each breath lasts longer
2. Raise the cycle threshold (ETS %)
3. Lower PS
4. Make the trigger more sensitive

## Respuesta del original para este ejemplo

Lower the cycle threshold (ETS %) so each breath lasts longer

## Explicación

Early cycle: with a short time constant, flow decays fast and hits a high ETS too soon, while the patient is still inhaling. Lowering ETS (e.g., from 50% to 25%) lets the breath run longer, matching neural Ti. Raising it would make things worse.

## Qué observar

Flow bends back toward baseline right after cycling.
