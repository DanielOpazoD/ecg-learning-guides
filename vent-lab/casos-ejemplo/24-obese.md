## Situación

BMI 52, hypoxemic, AC/VC with an inspiratory and an expiratory hold. Esophageal balloon in place.

## Pregunta

What is the best interpretation?

1. High airway resistance
2. Pleural pressure is high: end-expiratory PL is negative, so titrate PEEP up using Pes
3. Pplat is near 30: drop VT to 4 mL/kg
4. Auto-PEEP is raising Pplat

## Respuesta del original para este ejemplo

Pleural pressure is high: end-expiratory PL is negative, so titrate PEEP up using Pes

## Explicación

Pplat reflects lung plus chest wall. Pes (≈ pleural pressure) is very high, so end-expiratory transpulmonary pressure (total PEEP − Pes) is negative: the lung is being squeezed shut at end-expiration while the true distending pressure at end-inspiration (Pplat − Pes) is modest. Raising PEEP to keep PL,ee ≥ 0 targets the real problem; slashing VT based on Pplat alone would not.

## Qué observar

Two patients with the same Pplat can have very different lung stress. Esophageal manometry tells them apart.
