# 08. late

Dificultad: medium

Ejemplo generado por el motor original. La plantilla puede producir otras variantes.

## Situación

Awake, interactive, and complaining the ventilator is “hard to start a breath on.”

## Pregunta

Which patient-ventilator interaction is this?

1. Early trigger
2. Failed trigger
3. Late trigger
4. False trigger

## Respuesta del original para este ejemplo

Late trigger

## Explicación

Before each breath, airway pressure drops well below PEEP for a long time before the ventilator responds: the trigger is too insensitive, so there is a clinically important delay (> 100 ms) between effort and inflation.

## Qué observar

A prolonged pressure dip below baseline (or flow crossing zero) well before the breath starts.
