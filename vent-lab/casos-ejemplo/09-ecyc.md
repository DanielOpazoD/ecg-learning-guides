# 09. ecyc

Dificultad: medium

Ejemplo generado por el motor original. La plantilla puede producir otras variantes.

## Situación

Restrictive lungs on PSV with a high cycle threshold.

## Pregunta

Which patient-ventilator interaction is this?

1. Late cycle
2. Failed trigger
3. Early cycle
4. Expiratory work

## Respuesta del original para este ejemplo

Early cycle

## Explicación

Each breath ends while the patient is still inhaling: early in expiration the flow bends back toward baseline, breaking the smooth exponential decay. The ventilator cycled before the patient’s effort finished.

## Qué observar

Expiratory flow deviated toward baseline just after cycling. Early cycle is a common cause of double triggering.
