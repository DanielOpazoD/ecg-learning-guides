# 06. double

Dificultad: easy

Ejemplo generado por el motor original. La plantilla puede producir otras variantes.

## Situación

ARDS on low tidal volumes. The displayed rate is double what you expected.

## Pregunta

Which waveform pattern is this?

1. Failed trigger
2. Multiple (double) trigger
3. Late cycle
4. Dynamic hyperinflation (auto-PEEP)

## Respuesta del original para este ejemplo

Multiple (double) trigger

## Explicación

Two breaths in close succession without complete exhalation between them: multiple (double) trigger. In volume control the volumes stack, so the lung receives far more than the set VT.

## Qué observar

A second breath fires right after the first, before volume returns to zero.
