# 05. starve

Dificultad: easy

Ejemplo generado por el motor original. La plantilla puede producir otras variantes.

## Situación

Septic, acidemic and air-hungry. AC/VC with a low set flow.

## Pregunta

Which patient-ventilator interaction is this?

1. Early cycle
2. Increased elastic load
3. Late trigger
4. Severe work shifting (flow starvation)

## Respuesta del original para este ejemplo

Severe work shifting (flow starvation)

## Explicación

The pressure scalar is scooped down during inspiration, below PEEP. The patient is pulling harder than the fixed flow can supply, so the patient is doing work on the ventilator. Severe work shifting is never acceptable.

## Qué observar

In volume control, patient effort shows up in the pressure scalar. Above baseline = work shifting; below baseline = severe.
