# 21. fix-failed

Dificultad: hard

Ejemplo generado por el motor original. La plantilla puede producir otras variantes.

## Situación

COPD on AC/VC with many unanswered efforts.

## Pregunta

Which change best addresses the root cause?

1. Increase VT so each breath satisfies the patient
2. Reduce dynamic hyperinflation: lower VT or RR, shorten inspiration, bronchodilate
3. Make the flow trigger more sensitive
4. Increase the set RR to match the patient

## Respuesta del original para este ejemplo

Reduce dynamic hyperinflation: lower VT or RR, shorten inspiration, bronchodilate

## Explicación

The efforts fail because of auto-PEEP: no trigger setting can detect an effort that never brings flow to zero. Shrink the trapped volume: lower VT/RR, shorten inspiratory time, treat bronchospasm. (In advanced practice, external PEEP up to ~80% of auto-PEEP can also unload triggering.) Bigger or more breaths make trapping worse.

## Qué observar

Over-assistance (too much volume) is itself a cause of failed triggers.
